========================================
 CodeMaster C 语言学习平台
========================================

【环境要求】
  Node.js 18 或更高版本
  下载：https://nodejs.org

【启动步骤】
  1. 解压本压缩包
  2. 打开命令行，进入项目目录
  3. 运行：start.bat

【AI 功能说明】
  AI 助手由 DeepSeek 提供支持。
  .env 文件中已包含测试用 API Key，仅用于本次作业演示。
  如需要，可自行前往 platform.deepseek.com 申请新 Key 替换。

【已知问题】
  - 直接双击 HTML 无法使用 AI 功能，必须通过 node 启动
  - 首次启动如遇 3000 端口占用，请修改 server.js 中的 PORT
