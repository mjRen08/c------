========================================
 CodeMaster C 语言学习平台
========================================

【环境要求】
  Node.js 18 或更高版本
  下载：https://nodejs.org
  选择安装版

【启动步骤】
  1. 解压本压缩包
  2. 打开命令行，进入项目目录
  3. 运行：start.bat
  4. 浏览器会自动打开 http://localhost:3000

--------------------------------------------------
 重要：全站只用这一个地址
--------------------------------------------------
  AI 助手、Wasm 编译器、图片全部由 server.js 这一个服务提供，
  所以只需要访问 http://localhost:3000，不要再另开别的端口或
  用 Live Server / 直接双击 HTML 打开，否则会出现"AI 能用在 3000、
  编译器要 http、图片又打不开"这种互相打架的情况。
  简单方式：直接双击start.bat，窗口自动拉起

  三个部分各自是怎么统一的：

  1) AI 助手（DeepSeek）
     - 前端请求的是同源地址 /api/ai，没有写死 localhost:3000。
     - 即使把网页放到别的端口，前端也会自动找到本机 3000 的后端
       （server.js 已开启 CORS），并给出明确的失败提示。

  2) Wasm 编译器（OJ 练习场）
     - 依赖走本站同源代理 /vendor/npm/...，不再直接跨域拉 CDN。
     - 首次使用会自动下载约 40 MB 并缓存到 .cache 目录
       （国内 npm 镜像，实测比 jsdelivr 快很多），
       之后完全本地命中，离线也能用。
     - 缓存目录已在 .gitignore 中忽略，不会污染仓库。

  3) 图片（制作团队头像等）
     - 头像文件名已改成纯 ASCII（zhang.jpg / ren.jpg ...），
       这样打包成 ZIP 发给别人时，不会因文件名编码不同而变成乱码。
     - 服务器会先对 URL 解码再找文件，即使是中文文件名也能访问。
     - 万一图片缺失，头像会自动显示姓氏文字，不再出现裂图。

--------------------------------------------------
【AI 功能说明】
  AI 助手由 DeepSeek 提供支持。
  .env 文件中已包含测试用 API Key，仅用于本次作业演示。
  如需要，可自行前往 platform.deepseek.com 申请新 Key 替换。

  .env 可配置项：
    DEEPSEEK_API_KEY      密钥
    PORT                  端口，默认 3000
    DEEPSEEK_MODEL        默认 deepseek-chat（直接输出答案）
                          改成 deepseek-flash 会用推理模型，
                          会先输出思考过程，需要同时调大
                          DEEPSEEK_MAX_TOKENS
    DEEPSEEK_MAX_TOKENS   单次回答的 token 上限，默认 2048

【手机 / 平板访问】
  1. 让手机和电脑连同一个 Wi-Fi（手机用流量不行）。
  2. 在电脑上运行 start.bat，命令行里会直接打印手机可用的地址，
     形如：
         [手机] 手机打开（需与电脑连同一个 Wi-Fi）：
              http://192.168.x.x:3000      [WLAN]
     注意要用 [WLAN] 那条；标了"虚拟网卡"的地址手机连不上。
  3. 把那条 http://...:3000 完整输入手机浏览器地址栏回车即可。

  打不开时依次检查：
    - 手机是不是连了别的 Wi-Fi / 流量？换成和电脑同一个 Wi-Fi。
    - 校园网或公共 Wi-Fi 常开启"客户端隔离"，会阻断手机与电脑互通。
      这种情况改用下面任一办法：
        a) 电脑开热点：Windows「设置 -> 网络和 Internet -> 移动热点」打开，
           手机连这个热点，然后访问 http://192.168.137.1:3000
        b) 手机开热点：电脑连手机热点，再重新运行 start.bat 看新打印的地址
    - 电脑上如果没弹出过防火墙提示，手动允许一次：
      用管理员身份运行 PowerShell，执行
        New-NetFirewallRule -DisplayName "CodeMaster 3000" -Direction Inbound -Protocol TCP -LocalPort 3000 -Action Allow

  说明：手机上 OJ 判题、AI 助手都能正常用（Wasm 编译器是本站同源加载的，
  不依赖手机访问外网）。四个小游戏目前仍是键盘操作，手机端只是能打开看。

【常见问题】
  - 打开页面提示"没找到 AI 后端"
      -> 说明没通过 start.bat 启动。请运行 start.bat 后访问
        http://localhost:3000。

  - OJ 提示"Wasm 编译器不可用，已切换为 JS 严格结构检查"
      -> 首次使用需要下载约 40 MB 编译器依赖。请保持网络畅通，
        在命令行窗口可以看到下载进度；下载完成后刷新页面即可，
        之后每次打开都是秒开（已缓存到 .cache）。

  - 端口 3000 被占用
      -> 修改 .env 里的 PORT，启动后按命令行提示的地址访问即可。

  - 想清空编译器缓存重新下载
      -> 删除项目下的 .cache 目录。

  - 想改 OJ 题库（题目、测试点、参考答案）
      -> 题目源数据在 develop/data/batch-*.js。改完后在 develop 目录下依次执行
         check-structure.mjs、run.mjs verify-all.mjs、build-data.mjs，
         由 build-data.mjs 重新生成 assets/js/oj-data.js（网站加载的就是它）。
         细节见 develop/README.md；平时使用网站不需要碰这个目录。
