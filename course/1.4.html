第4章 · 基本输入与输出

可学习
📘 课程：C语言基础入门⏱ 预计 20 分钟🎯 难度：入门

学习目标

  • 掌握 printf 的基本输出方式
  • 理解 scanf 读取数据的方法
  • 学会使用地址运算符 &
  • 能够完成简单的交互式程序

课程内容

先来一个小场景

如果程序每次运行都只能计算同一组数字，它就不够灵活。让用户输入姓名、年龄或成绩，程序才能根据不同数据给出不同结果。

为什么要学这个

输入让数据从用户进入程序，输出让结果回到屏幕。掌握这两个过程，代码才真正具备和人交流的能力。

printf 用于把文字和数据输出到屏幕。输出变量时，要在字符串中放入对应的格式说明符，再把变量写在逗号后面。格式说明符必须和数据类型匹配。

output.c
int age = 18;
double height = 1.72;

printf("年龄：%d\\n", age);
printf("身高：%.2f 米\\n", height);
提示：\\n 表示换行，%.2f 表示浮点数保留两位小数后输出。

读取键盘数据时，可以使用 scanf。它的第一个参数是格式字符串，后面跟变量的地址。对于普通变量，需要在变量名前加地址运算符 &，告诉程序应该把输入结果放到哪里。

input.c
#include <stdio.h>

int main() {
    int number;
    printf("请输入一个整数：");
    scanf("%d", &number);
    printf("你输入的是：%d\\n", number);
    return 0;
}

当用户输入整数时使用 %d，输入浮点数时使用 %f 或 %lf，输入单个字符时使用 %c。输入格式不匹配可能导致读取失败，因此要同时检查变量类型和格式说明符。

一次读取多个数据时，可以在格式字符串中写多个说明符，并按顺序传入多个地址。用户输入的数据通常用空格或换行分隔，程序会按照格式依次读取。

sum.c
int first, second;
scanf("%d %d", &first, &second);
printf("和为：%d\\n", first + second);

字符输入有一个容易忽略的细节：按下回车后，输入缓冲区中可能还保留换行符。初学阶段应当先保证格式和变量类型正确，遇到字符读取异常时，再检查输入缓冲区中的剩余内容。

输出不仅可以展示最终结果，也可以在程序运行过程中提示用户下一步做什么。清晰的提示语能让交互过程更容易理解，例如输入前说明需要输入什么，输出时说明结果代表什么。

小挑战

  • 为什么 scanf("%d", &number) 中需要写 &number？
  • 如果变量是 double，输入和输出时应该注意哪些格式说明符？
  • 如何让程序一次读入两个整数并输出它们的平均值？
  • 为什么给用户的提示语会影响程序的易用性？

设计输入输出时，可以按照“提示输入、读取数据、处理结果、说明输出”的顺序组织代码。这样的结构清楚地展示了数据从用户进入程序、经过计算、再变成结果的过程。

一句话总结

printf 负责把信息展示出来，scanf 负责把用户数据读进变量，格式说明符和变量类型必须相互匹配。
