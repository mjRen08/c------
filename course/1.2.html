第2章 · 变量、常量与数据类型

可学习
📘 课程：C语言基础入门 ⏱ 预计 20 分钟 🎯 难度：入门

学习目标

  • 理解变量、常量和数据类型的区别
  • 掌握 int、float、double 与 char 的基本用法
  • 学会声明、初始化和修改变量
  • 能够根据数据特点选择合适的类型

课程内容

先来一个小场景

想象你在制作一个成绩记录程序：学生姓名不会随时改变，但分数可能更新，班级人数还需要参与计算。程序必须知道每份数据是什么、能不能修改，以及应该占用怎样的存储空间。

为什么要学这个

变量就像程序里的储物盒，数据类型决定盒子能放什么，常量则表示创建后不应随意改变的数据。把三者分清楚，才能让程序计算正确，也能避免不必要的内存浪费。

上一章我们认识了 C 程序的入口和基本结构，这一章开始学习程序要处理的“材料”：数字、字符以及由它们组成的数据。C 语言不会把所有数据都当成同一种东西，而是要求我们在声明变量时明确写出类型。

变量是一个有名字的存储空间，它的值在程序运行过程中可以改变。例如，游戏分数、商品数量和当前温度都适合使用变量保存。声明变量时通常要写出类型和名称，初始化则是在声明时给它一个起始值。

一个记录商品信息的小程序可以这样写：

data.c 
#include <stdio.h>

int main() {
    int quantity = 3;
    double price = 12.5;

    printf("数量：%d\n", quantity);
    printf("单价：%.2f\n", price);
    return 0;
}
提示：先判断数据是什么，再选择类型。数量通常是整数，带小数的价格则更适合使用浮点类型。

上面的 quantity 是 int 类型，适合保存没有小数部分的整数；price 是 double 类型，可以保存更精确的小数。变量名应当表达含义，像 price 比 x 更容易让别人读懂。

C 语言常见的基本类型包括：int 表示整数，float 表示单精度浮点数，double 表示精度更高的浮点数，char 表示单个字符。类型不只是标签，它还会影响数据的表示范围、精度以及程序为它分配的存储空间。

types.c 
int count = 20;
float temperature = 36.5f;
double distance = 128.75;
char grade = 'A';

字符要使用单引号，例如 'A'；字符串则是多个字符组成的文本，要使用双引号，例如 "CodeMaster"。字符和字符串看起来相似，但在 C 语言中不是同一种数据，写错引号可能导致编译错误或得到完全不同的结果。

有些数据在程序运行期间不应该被修改，例如圆周率、月份数量或一年的天数。这时可以使用常量。使用 const 修饰变量后，程序会把它当作只读数据处理：

constant.c 
const double PI = 3.1415926;
const int DAYS_IN_WEEK = 7;

double circleArea(double radius) {
    return PI * radius * radius;
}

常量名通常使用大写字母和下划线，这是一种便于识别的命名习惯。把固定值集中定义为常量，可以避免在代码中重复写数字，也能让修改规则变得更简单。

变量的值可以通过赋值语句改变，但赋值两边的类型要尽量匹配。例如，count = count + 1; 会让整数增加 1，而把小数直接放进整数变量时，小数部分可能被舍弃。编写程序时要留意这种类型转换，不要让数据在不知不觉中丢失精度。

输出不同类型的数据时，也要选择对应的格式说明符。%d 常用于整数，%f 用于浮点数，%c 用于字符，%s 用于字符串。例如，输出 double 时可以写成 printf("%.2f", price);，其中 .2 表示保留两位小数。

选择类型时不必只看“能不能存下”，还要考虑数据的含义。年龄、人数和数组下标通常是整数；身高、价格和平均分通常需要小数；性别标记或等级字符可以用 char。类型选择越准确，代码表达的信息就越清楚。

小挑战

  • 如果要保存图书数量、图书价格和图书等级，分别适合选择哪些类型？为什么？
  • 变量和常量有什么区别？把 const int MAX_SCORE = 100; 再赋值为 120 会发生什么？
  • 为什么字符 'A' 和字符串 "A" 不能简单看成同一种数据？
  • 如果用 int 保存带小数的平均分，可能产生什么问题？应该怎样改进？

理解变量、常量和数据类型之后，可以用“名称 + 类型 + 值”来检查一段声明：名称说明数据是谁，类型说明它是什么，值说明它当前保存的内容。这个思路会贯穿后面的输入、数组、函数和结构体学习。

学习这一章时，可以主动修改示例中的初始值，观察不同类型对输出的影响。把 quantity 改成别的整数，把 price 改成不同的小数，再尝试修改常量，编译器的反馈会帮助你理解“哪些数据可以改变，哪些数据应该保持固定”。

一句话总结

变量保存会变化的数据，常量保存不应变化的数据，数据类型则告诉 C 语言如何理解和存储这些数据。

这一章的重点不是记住所有类型的细节，而是形成选择类型的习惯：先分析数据的含义，再考虑它是否需要小数、是否允许修改以及输出时使用什么格式。这样写出来的程序会更准确，也更容易维护。

当你能够熟练声明变量、使用常量，并区分整数、浮点数和字符之后，就已经为下一步的运算符与表达式做好准备。后面的计算，本质上就是让这些不同类型的数据按照规则参与运算。
