第3章 · 运算符与表达式

可学习
📘 课程：C语言基础入门⏱ 预计 20 分钟🎯 难度：入门

学习目标

  • 掌握算术、关系和逻辑运算符
  • 理解表达式的值与运算顺序
  • 学会使用自增、自减和复合赋值
  • 能够写出简单的计算表达式

课程内容

先来一个小场景

程序保存了商品单价和数量，但只有把它们进行运算，才能得到总价。运算符就是连接数据的符号，表达式则是由数据和运算符组成的计算过程。

为什么要学这个

变量只是保存信息，表达式让信息产生结果。掌握运算符之后，程序才能完成计算、比较和条件判断。

C 语言中的运算符可以对一个或多个数据进行操作。最常见的是算术运算符：+、-、*、/ 和 %。其中 % 表示取余，常用于判断一个整数是否能被另一个整数整除。

arithmetic.c
int total = 17;
int groups = 5;

printf("商：%d\\n", total / groups);
printf("余数：%d\\n", total % groups);
提示：整数相除时结果仍是整数，17 / 5 的结果是 3，小数部分不会自动保留。

关系运算符用于比较两个值，例如 ==、!=、>、<、>= 和 <=。比较结果只有真或假，在 C 语言中通常用 1 表示真，用 0 表示假。

不要把 = 和 == 混淆。= 是赋值，把右边的值放入左边的变量；== 是相等比较，用来判断两边是否相等。

compare.c
int score = 86;
int passed = score >= 60;

printf("是否及格：%d\\n", passed);

逻辑运算符可以把多个判断组合起来：&& 表示并且，|| 表示或者，! 表示取反。例如，只有年龄大于等于 18 且拥有有效证件时，两个条件同时成立，结果才为真。

表达式的计算顺序由优先级决定。乘除通常先于加减，括号可以明确改变顺序。面对较复杂的表达式，主动加括号比依赖记忆优先级更清楚，也更不容易出错。

order.c
int result = 2 + 3 * 4;
int clearResult = (2 + 3) * 4;

printf("%d %d\\n", result, clearResult);

自增运算符 ++ 会让变量增加 1，自减运算符 -- 会让变量减少 1。它们可以写在变量前面或后面，但在复杂表达式中容易造成阅读困难，初学时建议单独成句。

复合赋值运算符把运算和赋值合在一起，例如 score += 5 等价于 score = score + 5，count *= 2 等价于 count = count * 2。它们能让更新变量的代码更简洁。

小挑战

  • 为什么 17 / 5 和 17.0 / 5 的结果不同？
  • = 与 == 分别表示什么？
  • 如何判断一个整数是偶数？可以使用哪个运算符？
  • 表达式 2 + 3 * 4 和 (2 + 3) * 4 为什么结果不同？

写表达式时，可以先把每个数据的含义说清楚，再选择对应运算符。算术运算负责计算，关系运算负责比较，逻辑运算负责组合条件，三类运算共同构成了程序处理问题的基础。

一句话总结

运算符规定如何处理数据，表达式把数据和运算规则组合起来并产生结果。
