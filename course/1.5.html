第5章 · 编写第一个完整程序

可学习
📘 课程：C语言基础入门⏱ 预计 25 分钟🎯 难度：入门

学习目标

  • 能够拆解一个小程序的需求
  • 综合使用变量、运算和输入输出
  • 理解函数、注释与调试过程
  • 独立完成一个简单成绩统计程序

课程内容

先来一个小场景

现在要写一个成绩统计程序：用户输入三门课成绩，程序计算总分和平均分，并告诉用户是否达到及格线。这个任务会把前面学过的知识串成一条完整流程。

为什么要学这个

完整程序不只是把代码堆在一起，而是要经过需求分析、数据设计、计算处理、结果输出和测试。学会这个过程，才能把零散语法真正用于解决问题。

写程序前先明确需求：需要哪些输入、需要保存哪些数据、要进行什么计算、最后输出什么结果。对于成绩统计程序，可以准备三个浮点变量保存成绩，再用表达式计算总分和平均分。

score_report.c
#include <stdio.h>

int main() {
    double chinese, math, english;
    double total, average;

    printf("请输入三门成绩：");
    scanf("%lf %lf %lf", &chinese, &math, &english);

    total = chinese + math + english;
    average = total / 3;

    printf("总分：%.2f\\n", total);
    printf("平均分：%.2f\\n", average);
    return 0;
}
提示：先让程序完成一个清晰、可运行的版本，再逐步增加校验和扩展功能。

这段代码可以分成四个部分：声明变量、读取输入、计算结果、输出结果。这样的程序分解能帮助我们逐段检查问题，而不是面对整页代码无从下手。

变量的命名应该表达用途，average 比 x 更容易理解。对于重复出现且含义固定的数值，可以使用常量，例如把及格线定义为 const double PASS_LINE = 60.0;。

check_result.c
const double PASS_LINE = 60.0;

if (average >= PASS_LINE) {
    printf("结果：通过\\n");
} else {
    printf("结果：需要继续练习\\n");
}

这里出现了条件判断，它会根据平均分选择不同的输出。大括号中的代码称为代码块，缩进能帮助读者看出哪些语句属于同一个条件分支。

程序写完后要进行测试。可以准备正常成绩、满分成绩、刚好 60 分和包含小数的成绩，检查输出是否符合预期。测试不是只看程序能否运行，还要观察边界数据时结果是否正确。

遇到问题时，先区分语法错误和逻辑错误。语法错误通常会阻止编译，例如缺少分号或括号不匹配；逻辑错误可以编译运行，但结果不正确，例如把总分除以 2 而不是 3。

debug_steps.txt
1. 先阅读编译器提示
2. 缩小出错范围
3. 输出关键变量检查中间结果
4. 用一组简单数据重新验证

注释可以记录代码的目的，但不应重复描述每一行显而易见的操作。好的注释更适合解释“为什么这样设计”，例如说明及格线的业务规则或某个计算公式的来源。

小挑战

  • 成绩统计程序需要哪些变量？它们分别应该使用什么类型？
  • 如果把平均分除以 2，程序能运行但结果错误，这属于哪一类问题？
  • 如何测试“刚好达到及格线”的情况？为什么边界测试很重要？
  • 你还能为这个程序增加什么功能，例如最高分、最低分或等级评价？

从需求到代码的过程可以反复练习：先写出输入和输出，再补充数据和计算，最后增加判断与校验。每次只增加一个小功能，程序更容易保持可运行状态。

一句话总结

完整程序需要把数据、表达式、输入输出、判断和测试组织成一条清晰的解决问题流程。

完成这一章后，你已经走完了 C 语言基础入门的第一轮学习。接下来可以继续学习循环、数组和函数，把小程序扩展成更有能力的项目。
